# 设计审查实施记录

本次以 design-taste-frontend 的信息层级、视觉一致性、可读性、反馈和键盘操作原则改进现有工具界面。保留中性表面与蓝色主操作；官网首屏、摄影、宣传动效和营销页面检查器不适用于这些工作界面。

## 已实施

| 范围 | 结果 |
| --- | --- |
| 翻译 | 常驻翻译/取消文字按钮；服务选择降为浅色选中态；错误独立于译文；重试及服务账号入口；原文变化使结果失效；失败、过期和执行中禁止复制；操作文案统一为复制、复制并关闭、粘贴到原窗口。 |
| 字体与颜色 | 控件正文 13 DIP、内容 14 DIP、辅助文字 12 DIP；去掉设置提示的二次透明度；加深辅助文字与成功色；共用圆角资源，减少普通内容面板的阴影。 |
| 设置 | 页名与窗口标题明确；保存状态在页内显示；表单标签关联可访问名称；账号测试结果留在分组内，参数改变后失效，晚到的测试结果不会验证另一组参数。 |
| 剪贴板 | 图片缩略图为紧凑的完整预览；时间、来源、尺寸集中在内容旁；收藏点击区域扩大；底部显示键盘与鼠标操作提示。 |
| OCR | 标明可编辑；本地/腾讯云/AI 来源使用中文名称；复制后保留窗口并显示反馈；Ctrl+Enter 复制、Esc 关闭。 |
| 截图 | 选中工具增加描边与可访问状态；翻译显示识别、挑选翻译、排版阶段；完成操作明确为复制截图并关闭。 |
| 传输桌面端 | 连接前显示扫码与网络提示，连接后自动压缩为摘要并可展开；添加文件夹降为次级按钮；清除设备明确影响全部已记住设备及当前会话。 |
| 手机网页 | CSS 变量对应桌面配色；文件输入保持键盘可达；方向键切换标签页；原生模态对话框及循环焦点、Escape 拒绝、焦点恢复；任务按 ID 更新以保持焦点；目录未变化时不重绘；状态以手机视角描述；空状态与独立操作错误；减少动画设置覆盖加载指示器。 |
| 托盘 | 初始焦点、方向键与 Home/End 导航；可访问名称与快捷键；加宽菜单适配新字体。 |
| 文档 | 更新五张桌面产品图并新增手机图，增加交互和可访问性回归清单。 |

## 验证

- `dotnet build`：零警告、零错误。
- `dotnet test Tests/STool.Tests.csproj`：401 项通过、零跳过。新增 WPF 交互测试覆盖失败结果、旧译文失效、取消后迟到响应及复制保护。
- `node --test scripts/Test-LanTransferWeb.cjs`：Chrome 实际浏览器检查通过，覆盖文件选择、标签页、轮询焦点、状态切换、弹窗焦点、拒绝与恢复、认证焦点、减少动画及 320/390/768/1280px 横向溢出。
- 使用实际 WPF 模板、隔离的示例配置和文件生成截图，检查翻译、设置、服务账号、OCR、剪贴板、传输窗口的最小尺寸；翻译额外输出 1.5x、2x 渲染。截图使用演示文本与网络地址，不代表真实连接或在线翻译服务验证。
- 本地详细检查图片在 `artifacts/design-review/`，可分享的产品图片在 `docs/product-readme/assets/`。

## 尚需设备实测

位图按比例渲染不能替代真实多显示器 DPI 切换；仍需按回归清单验证 Windows 100%/150%/200% 显示缩放、Narrator、手机 VoiceOver/TalkBack、真实设备文件与文件夹选择，以及完整网络传输。浏览器自动化使用拦截的 API 示例数据，不访问用户的设备或服务账号。

生成设置预览时，现有通用设置页面会自动校正开机启动注册表路径。此次已将该值恢复为正在运行的正式程序路径，之后的预览采用保存/恢复保护。未来预览工具应沿用同样的隔离方式。
