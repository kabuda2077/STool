# 设计审查实施与修正

首轮设计调整增加了常驻说明、拆分翻译工具栏，并改变了全局字体和分段选中态。实际使用反馈表明这些变化破坏了原有的紧凑与规整感。本轮以 `c18c2b6` 的桌面视觉为基准恢复布局，保留必要的状态保护与键盘支持。

## 当前界面

- 翻译采用剪贴板历史的标题下工具栏：左侧为「谷歌 / 腾讯 / AI」，蓝底白字表示选中；右侧为语言选择，与剪贴板搜索框共用容器样式。输入面板右下角为「×」清空图标和「翻译」文字按钮，翻译中显示「取消」，空白时禁用。输入为空时只显示一行占位提示；原文与译文正文、上下占位文字统一使用 12 DIP 字号；占位提示使用 0.65 透明度、自然行高，并与文本视图的 2 DIP 水平留白对齐，正文颜色保持不变。语言选项内容按自身尺寸布局，避免展开下拉菜单时被拉伸，造成已选文字位移。
- 翻译与剪贴板共用标题下布局和 36 DIP 工具栏；翻译首个面板补齐剪贴板记录的 4 DIP 顶部间距。引擎按钮与剪贴板分类均使用 58 DIP 最小宽度，结果操作宽度独立于引擎组。
- 结果区只保留一个空状态提示。成功时直接显示译文；失败、取消、原文修改时才出现状态区域。复制、复制并关闭、复制并输入保持整组，位于结果区右下角。
- OCR 恢复标题下直接进入内容区，删除常驻编辑说明。编辑能力、Ctrl+Enter 复制、Esc 关闭及复制后继续编辑保留。
- 局域网连接区恢复目录、地址、验证码三行；移除设备回到验证码一行。二维码说明放入 ToolTip，添加文件与添加文件夹恢复相同按钮样式。连接后收起详情的功能保留。
- 剪贴板恢复原有行布局和缩略图尺寸，移除新增底部说明；原有键盘操作保留。
- 全局字体、颜色与间距恢复审查前的桌面资源，托盘恢复原有宽度。按用户确认保留圆角归档：普通容器使用 8 DIP、设置分组使用 12 DIP；移除普通工具内容面板的轻阴影。菜单、浮层、工具栏及分段选中态的阴影维持原样。键盘焦点与图标可访问名称保留。
- 设置页保留页名和实际保存反馈，不再常驻「更改自动保存」说明。

## 保留的行为修复

翻译失败信息不能作为译文复制；修改原文使旧结果失效；取消后迟到请求不能覆盖结果。错误仍有重试及账号配置入口。账号测试结果会随参数变化失效。手机网页的文件选择、模态焦点、标签导航、轮询焦点保持及方向文案修复保持不变。截图翻译阶段提示仅在处理期间出现。

## 验证与范围

- 构建零警告、零错误；401 项测试通过、零跳过。
- 翻译交互测试增加了空白与成功状态无额外状态行、失败时显示状态的断言，继续覆盖错误复制保护、旧结果失效及迟到响应。
- 使用实际 WPF 模板与示例数据生成截图，检查翻译空白、成功和最小窗口布局，以及传输、OCR、设置、剪贴板等界面。产品图片已同步更新。
- 手机网页代码本轮未变更，沿用首轮已经通过的 Chrome 交互检查。
- 截图使用演示配置、文本及地址；位图渲染不替代真实多显示器 DPI 切换或移动设备读屏测试。手工验收项见 `manual-regression-checklist.md`。
- 预览设置页面会触发现有的开机启动路径校正逻辑；生成截图时保存并恢复注册表值，避免改变正式程序的自启路径。

## 全面审查后的交互与可访问性修复

在 `fix/impeccable-ui-review` 分支落实本次 16 项审查问题，保留现有紧凑布局与蓝底白字分段外观。

- 剪贴板导航与粘贴按键限定于搜索、列表上下文；截图工具栏保留聚焦控件自己的按键处理，同时保持 Esc、Ctrl+S 可用。
- 设置自动保存失败时保留草稿，在原状态区提供重试；未保存成功前不切页或关闭窗口，导航选中态与页面标题保持一致。
- 设置开关由实际复选框统一驱动变化回调，支持 UI Automation Toggle；初始化和失败回退不触发重复保存。密钥字段将标签传给密文、明文两个输入控件。
- 翻译服务、剪贴板分类和传输视图采用原生 RadioButton 选择语义；Checked 同步业务状态，辅助技术和程序选择也会更新对应内容。
- 截图保存期间只隐藏覆盖层，取消或写入失败后恢复同一选区、标注与焦点；PNG 编码与写入移至后台。保存期间再次触发截图不会重新显示已禁用的覆盖层。
- 剪贴板查询失败显示原位错误与重试；图片支持 F3 和键盘上下文菜单预览，关闭后恢复焦点。
- 获取模型和测试模型按请求代次、平台、当前凭据丢弃过期响应与错误，包括视觉模型切换共用账号的情况。
- 成功测试文字使用新增 `SuccessTextBrush`，保留亮绿色状态点和截图选区；手机危险操作文字改用深红前景，取消与拒绝的对比度均超过 5.9:1。Toast 改为受宽度约束的 Grid，长消息可完整换行。
- 手机上传失败显示在当前可见错误区域，保留所选文件供重试；准备和上传全程锁定文件选择，并始终在结束时恢复控件。
- 首次连接区分网络故障与验证失败，提供重试并保留二维码令牌；无效令牌回到验证码验证，不自动重试循环。
- 目录响应按导航版本校验，切页、退出和认证重置后不会覆盖当前状态；首次目录加载被切页打断时，返回下载页可重新加载已接收的目录。
- 手机目录全选批量修改选择集合后统一更新状态，避免逐项扫描整个目录，并保留控件与焦点。
