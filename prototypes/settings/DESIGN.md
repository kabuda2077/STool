# 设置界面设计标准 · 连续内容面板

本标准只适用于独立浏览器设置原型。用户最新指定参考 Linear 的整体空间和视觉权重，并去掉导航、快捷键等重复表达名称的装饰图标。保持 STool 的浅色与蓝色，不照搬参考图的暗色主题。

## 视觉方向

窗口和侧栏采用连续的浅灰底色，主体为单一的近白内容面板。内容区域限制阅读宽度，用文字主次、组间留白和轻分隔组织信息。取消重复的大圆角分组框；控件默认安静，悬浮、聚焦、编辑时强化反馈。

Magpie 仍作为控件细节的辅助参考；当前空间结构以用户提供的 Linear 截图为准。现有 WPF 设置页不作为设计参考。

## 色彩与权重

- 窗口与侧栏 `#F1F2F4`；主面板 `#FDFDFE`；控件 `#F5F5F7`。
- 主文案 `#222329`；分组标题 `#43454F`；辅助 `#666873`。
- 导航选中使用中性灰底与较强字重，无阴影；不再作为高对比白色按钮。
- STool 蓝 `#2554C7` 用于主要操作、开关开启和焦点。
- 成功 `#15803D`、错误 `#C42B32`，伴随明确文字或状态图形。
- 内容分组无边框、无阴影。窗口阴影和必要的浮层层次保留。

## 图标规则

- 标题、导航、快捷键条目、服务账号页签、应用排除列表不加装饰图标。
- 保留确有操作用途的图标：显示密码、移除、展开、返回、窗口操作。
- 保留等待、成功、错误状态图形，帮助辨识状态。
- 服务商真实标识仅在当前账号身份区域出现一次，尺寸 24，无额外底座。来源和许可证见 assets/README.md。
- 不用图标填补留白；通过排版和内容关系建立层级。

## 交互与组件

1. 通用、剪贴板、OCR、翻译、服务账号共用布局参数与 CSS tokens。
2. 快捷键点击录制，Esc 取消，冲突保留旧值并就地显示。键帽表达当前值，悬浮反馈覆盖录制区域。
3. 应用排除为纯文字紧凑列表，移除按钮靠近对应行；添加入口位于列表末尾。
4. 账号采用文字页签，当前页签以字重和底线标记。当前服务身份、字段和测试区均直接置于主体面板。
5. 高级设置使用紧凑文字披露，只有入口响应悬浮。
6. 保存与服务测试状态分别显示。凭据变化后旧结果失效；异步更新不打断输入焦点或收起高级设置。
7. 120–160ms 状态过渡；遵循减少动态效果，不做页面入场编排。

## 验证

组件样板和五页同步。检查默认、紧凑、窄视口和 150% 放大；确认单/双行开关等高、纯文字导航与快捷键对齐、服务标识可加载，以及完整交互回归。

浏览器原型不连接真实配置或账号。150% 放大不替代 WPF 的系统 DPI 校准。原生落地时重新核验字体、焦点和真实服务状态。
