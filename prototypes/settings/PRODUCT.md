# STool 设置原型

## 已确认的产品事实

- STool 是 Windows 托盘工具，提供截图、OCR、翻译、剪贴板历史和局域网传输。
- 本原型只探索设置体验，不连接真实配置、注册表、剪贴板、凭据或云服务。
- 五个入口依次为：通用、剪贴板、OCR、翻译、服务账号。
- 功能依据现有产品的配置与行为。现有设置页的视觉与布局不是设计参考。
- 视觉参考为独立工具面板的配色与系统字体、Magpie 的控件细节，以及用户最新提供的 Linear 截图：连续空间、弱边界、明确的视觉权重。用户要求去掉导航、快捷键等每项重复出现的装饰图标。
- 用户明确希望从零设计，简洁、优雅、现代，与其他工具协调但不必相同。交互已获认可；视觉需要整体协调，避免表单感、重复卡片和多余图标。当前版本使用单一主体面板与收敛的阅读宽度。
- 用户需要打开浏览器持续查看界面，修改后自动更新；先验证组件、通用与账号，再覆盖全部五页。

## 使用任务

调整行为与快捷键；管理剪贴板保留与排除；为 OCR 和翻译选择服务；配置、复用及验证服务账号。配置状态与连接测试状态必须区分。

## 原型边界

所有数据为演示数据。修改只留在当前浏览器；服务测试为明确标记的模拟结果。不可要求输入真实密钥。真实 Windows 语言列表、系统快捷键占用和服务连通性留待 WPF 实现验证。

## 成功标准

- 相同类型的行、控件、操作、反馈有稳定的结构，不随是否有说明随意改变尺寸。
- 默认、悬浮、聚焦、禁用、等待、错误都能直接在原型中检查。
- 账号配置入口能定位到相关服务并返回来源页。
- 两种桌面尺寸以及浏览器放大后仍然可操作。
- 规范以可交互的组件样板和 DESIGN.md 共同表达。
